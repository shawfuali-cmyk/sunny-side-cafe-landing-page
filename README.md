# Sunny Side Cafe — Responsive Landing Page Demo

A fictional café landing page portfolio sample built with semantic HTML5 and CSS3.

## Features
- Responsive layout for desktop, tablet, and mobile
- Navigation links to page sections
- Menu cards, location/hours section, and contact email link
- CSS-only illustration; no stock photos or image downloads
- Accessible labels and basic page metadata

## Files
- `index.html` — page content and structure
- `style.css` — layout, colours, typography, and responsive breakpoints

## Preview
Enable GitHub Pages in repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Notes
Sunny Side Cafe is a fictional demo brand. The address, opening hours, prices, and email are illustrative placeholders, not a real business listing.

## Tools
HTML5, CSS3, GitHub Pages. Fonts load from Google Fonts when internet access is available; fallback fonts are included.
